# Phonon chain project
## About the project
Simulation of phonons in 1D atomic chains (monatomic and diatomic):
dispersion relations, density of states, heat capacity (exact vs.
Einstein vs. Debye), and a Streamlit app.
## About me
I am a physics master's student learning Python, Git and Claude Code.
I know the basics of Python and Jupyter notebooks.
## How to work with me
- Keep code simple and readable; prefer clear code over clever code.
- Explain what you changed and why, in a few sentences.
- Put physics functions in src/phonons.py, with docstrings.
- Use NumPy and Matplotlib. Use reduced units (C = m = a = hbar = k_B = 1).
- Do NOT run git commit or git push. I do all Git commands myself.
- Ask me before adding new packages.
